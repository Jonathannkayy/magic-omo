# Security policy

Please report vulnerabilities **privately** via GitHub's private vulnerability reporting:
**Security → Report a vulnerability** on https://github.com/Jonathannkayy/magic-omo/security/advisories/new.

Do not open public issues for security problems. You should get an acknowledgement within 7 days.

Supported: the latest released `0.x` version.

In scope: anything magic-omo writes or executes (config edits, vendored package install/verification, guard units). Vulnerabilities in Magic Context or OMO Native themselves should go to those projects.
