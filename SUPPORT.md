# Support

- **Questions / ideas:** GitHub Discussions on this repository.
- **Bugs in magic-omo:** open an issue using the bug template and include `magic-omo doctor --json`.
- **Bugs in Magic Context:** https://github.com/cortexkit/magic-context/issues
- **Bugs in OMO Native / oh-my-openagent:** https://github.com/code-yeongyu/oh-my-openagent/issues

This is a volunteer-maintained, unofficial community project; there is no SLA.
